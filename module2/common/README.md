# Common Library

Набор базовых утилит, используемых в калькуляторе и телефонной книге.

## Возможности

- **`Vector`** — динамический массив общего назначения. Позволяет хранить данные любого типа, поддерживает функцию-деструктор для элементов (полезно для массивов строк). Автоматически расширяется при добавлении новых элементов.
- **`String Utils`** — вспомогательные функции для работы со строками (например, `duplicate_string` для безопасного копирования).
- **`Input Utils`** — функции для безопасного чтения строк из `stdin`, удаления символов перевода строки и запроса числовых значений с валидацией (`ask_for_uint32`).

## Структура

- `include/` — публичные заголовочные файлы.
- `src/` — реализация.
- `tests/` — юнит-тесты (Unity).

```bash
# Сборка библиотеки
make

# Сборка и запуск тестов
make test
```

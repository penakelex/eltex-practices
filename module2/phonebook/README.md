# Phonebook

Консольное приложение для управления списком контактов.

## Возможности

- **Хранение данных**: Ф.И.О., место работы, должность, а также динамические списки телефонов, email, соцсетей и мессенджеров.
- **Валидация**: Обязательными для заполнения являются только имя и фамилия.
- **Управление**: Добавление, редактирование (выборочное или всех полей сразу) и удаление контактов.
- **Редактирование по маске**: Возможность выбрать конкретные поля для изменения, введя их номера через запятую (например, `1,3,5`).

## Архитектура

- `contact.c` — структура контакта и управление памятью (динамические списки строк).
- `phonebook.c` — обертка над динамическим массивом контактов.
- `fields.c` — парсинг пользовательского ввода для выбора полей.
- `menu.c` — интерактивное меню (бизнес-логика взаимодействия с пользователем).
- `view.c` — форматированный вывод контактов в консоль.

## Использование

```bash
make
./build/bin/phonebook
```

Приложение предложит интерактивное меню для работы со списком.

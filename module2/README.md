# Module 2: C Applications

Hазработка приложений на языке C под Linux.

## Архитектура

Проект разделен на три независимых компонента:
1. **`common/`** — вспомогательная библиотека (динамический массив `Vector`, утилиты для работы со строками и вводом-выводом).
2. **`calculator/`** — калькулятор, поддерживающий инфиксные выражения. Использует рекурсивный спуск для построения AST (абстрактного синтаксического дерева) и таблицу команд с указателями на функции.
3. **`phonebook/`** — телефонная книга с возможностью добавления, редактирования и удаления контактов. Поля хранятся в динамических массивах.

## Сборка и запуск

```bash
# Собрать всё
make all

# Запустить калькулятор
./calculator/build/bin/calculator

# Запустить телефонную книгу
./phonebook/build/bin/phonebook
```

## Тестирование

Для тестирования используется фреймворк **Unity**. Он скачивается автоматически при первом запуске тестов (в папку `third_party/Unity`). Вся сборка тестов и их запуск изолированы от основной сборки.

```bash
# Запустить все тесты во всех модулях
make test

# Запустить тесты только для калькулятора
make -C calculator test
```

## Инструменты разработки

- `make format` — автоматическое форматирование всего кода (требуется `clang-format`).
- `make format-check` — проверка форматирования (используется в CI).
- `make install-hooks` — активация `pre-commit` и `pre-push` хуков. `pre-commit` форматирует код и запускает тесты, `pre-push` просто запускает тесты.

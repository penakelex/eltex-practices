# Permissions

Калькулятор масок прав доступа к файлу. Позволяет разбирать права в буквенном
и цифровом виде, получать их из `stat()` для реального файла и модифицировать
chmod-подобными командами без применения изменений к самому файлу.

## Возможности

- **Два формата ввода.** Права можно задавать буквенно (`rwxr-xr-x`, `rwsr-xr-t`)
  или цифрово (`755`, `4755`, `0644`). Формат определяется автоматически.
- **Три представления.** Для любых прав выводится:
  - буквенное — `rwxr-xr-x`;
  - цифровое — `755` (3 цифры для обычных прав, 4 — при наличии
    setuid/setgid/sticky);
  - битовое — `000 111 101 101` (12 бит, сгруппированы по 3).
- **Права из файла.** Для указанного пути вызывается `stat(2)`, из `st_mode`
  извлекаются младшие 12 бит. Дополнительно выполняется `ls -ld` для наглядного
  сравнения с системной утилитой (сравнение только для чтения, атрибуты файла
  не меняются).
- **Модификация прав.** Поддерживаются команды, аналогичные `chmod`:
  - классы: `u`, `g`, `o`, `a` (или их отсутствие — эквивалентно `a`);
  - операции: `+`, `-`, `=`;
  - права: `r`, `w`, `x`, `X`, `s` (setuid/setgid), `t` (sticky);
  - несколько клауз через запятую: `u+x,g-w,o=r`.
  Результат только отображается — к файлу не применяется.

## Архитектура

- `permission_bits.c` — разбор и форматирование 12-битной маски:
  `permission_parse` (автоформат), `permission_parse_octal`,
  `permission_parse_symbolic`, `permission_to_symbolic`, `permission_to_octal`,
  `permission_to_binary`.
- `permission_stat.c` — обёртка над `stat(2)`, возвращает `PermissionStatResult`.
- `permission_modifier.c` — парсер и применение chmod-подобной команды:
  `permission_modify` (одна клауза или список через запятую).
- `permissions.c` — фасад со статусами: `permission_from_input`,
  `permission_from_file`, `permission_from_modify`, плюс функции форматирования.
- `view.c` — весь вывод в консоль, включая запуск `ls -ld` через `popen`.
- `main.c` — REPL (цикл чтения-вычисления-печати).

### Раскладка битов

| Бит | Значение        |
|-----|-----------------|
| 11  | setuid (`s`/`S`) |
| 10  | setgid (`s`/`S`) |
| 9   | sticky (`t`/`T`) |
| 8–6 | user `rwx`       |
| 5–3 | group `rwx`      |
| 2–0 | other `rwx`      |

В буквенном представлении `S`/`T` (заглавные) означают, что специальный бит
установлен, а соответствующий бит execute — нет (как в `ls -l`).

## Использование

```bash
make
./build/bin/permissions
```

Приложение запускает интерактивное меню:

| Пункт | Действие |
|-------|----------|
| `1`   | Ввести права вручную (`755` или `rwxr-xr-x`) — показать все три представления. |
| `2`   | Ввести имя файла — получить права через `stat`, вывести представления и строку `ls -ld` для сравнения. |
| `3`   | Ввести текущие права и chmod-подобную команду — вывести исходные и новые представления. |
| `?`   | Повторить меню. |
| `q`   | Выход. |

### Примеры chmod-команд

| Команда              | Смысл |
|----------------------|-------|
| `u+x`                | Добавить execute владельцу |
| `g-w`                | Убрать write у группы |
| `o=r`                | Заменить права остальных на read |
| `a-w`                | Убрать write у всех |
| `u+s`                | Установить setuid (сохранив остальные биты) |
| `u-s`                | Снять setuid |
| `o+t`                | Установить sticky |
| `u+x,g-w,o=r`        | Несколько клауз через запятую |
| `u=rw`               | Полностью заменить права владельца (включая снятие `s`) |

## Тестирование

```bash
make test
```

Фреймворк **Unity** скачивается автоматически при первом запуске тестов в
`../third_party/Unity/src` (общий для всех модулей `module2`). Тесты
изолированы от основной сборки и не мешают ей.

Покрыто:

- разбор цифровых и буквенных прав, включая специальные биты `s`/`S`/`t`/`T`;
- некорректные входы (неверная длина, недопустимые символы, `nullptr`);
- форматирование в буквенное, цифровое и битовое представление;
- chmod-модификаторы: `+`, `-`, `=` для всех классов, специальные биты,
  списки через запятую, некорректные команды;
- `stat` на реальном файле (создаётся и удаляется в `/tmp`) и на
  несуществующем пути.

## Инструменты

- `make` — собрать приложение `build/bin/permissions`.
- `make test` — собрать и запустить юнит-тесты.
- `make clean` — удалить каталог `build/`.

Форматирование проверяется общими целями из `module2/Makefile`:
`make -C .. format` и `make -C .. format-check` (требуется `clang-format`).

## Зависимости

- C23-совместимый компилятор (`clang` по умолчанию, переопределяется через
  `make CC=gcc`).
- POSIX.1-2008: `stat(2)` и `popen(3)`/`pclose(3)`. В `view.c` включён
  `#define _POSIX_C_SOURCE 200809L`, чтобы `popen` был доступен при строгой
  сборке `-std=c23`.
- `curl` — только для первой загрузки Unity при `make test`.

## Ограничения

- Поддерживаются только младшие 12 бит классических прав POSIX. ACL, xattr,
  capabilities не затрагиваются.
- Изменения прав по пункту `3` **не применяются** к файлу — это требование
  задания; для реального изменения используйте `chmod`.
- `chmod`-команда не поддерживает `X` в смысле «execute только для каталогов
  или для файлов, где уже есть execute» — в реализации `X` трактуется как `x`.

# Calculator

Интерактивный калькулятор, поддерживающий математические выражения.

## Возможности

- Вычисление выражений с учетом приоритета операций и скобок (рекурсивный спуск).
- Поддержка унарных операций (смена знака) и бинарных (`+`, `-`, `*`, `/`, `^`).
- Поддержка математических функций: `sqrt`, `sin`, `cos`, `tan`, `asin`, `acos`, `atan`, `ln`, `log`, `exp`, `abs`, `neg`.
- Поддержка констант: `pi`, `e`.
- Построение AST (абстрактного синтаксического дерева) для корректной обработки сложных вложенных выражений.
- Динамическая таблица команд: добавление новой функции требует лишь добавления записи в массив `COMMANDS` (указатели на функции).

## Архитектура

- `parser.c` — лексический и синтаксический анализ, построение AST.
- `ast.c` — структура дерева и его рекурсивное вычисление.
- `command.c` — таблица доступных операций и функций.
- `calculator.c` — фасад, связывающий парсер и вычислитель, возвращающий статус операции.
- `view.c` — вывод в консоль (интерфейс).
- `main.c` — REPL (цикл чтения-вычисления-печати).

## Использование

```bash
make
./build/bin/calculator
```

Введите выражение, например: `2 + 3 * sin(pi / 2)`. Для выхода введите `q`, для справки — `?`.

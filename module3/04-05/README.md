# Задания 4–5: общая библиотека Производитель-Потребители

Общий код для заданий 4 (System V IPC) и 5 (POSIX IPC): односвязный список
блоков в разделяемой памяти, логика производителя и потребителей, вывод.
Различия между заданиями скрыты за таблицей операций `IpcOps` (`ipc.h`) —
ручной vtable: каждое приложение передаёт свою реализацию
(`ipc_system_v_ops()` или `ipc_posix_ops()`), а `producer_run`/`consumer_run`
работают с ней через диспетчеры `ipc_memory_*`/`ipc_semaphore_*`.

Сборка: `make` (статическая библиотека `build/lib/libpc_common.a`),
`make test` — юнит-тесты списка блоков (Unity).

# cross-01 — echo client/server на raw-сокетах

Кросс-задание 1 (raw sockets + САОД + signals).

Echo-сервер и echo-клиент поверх `socket(AF_INET, SOCK_RAW, IPPROTO_UDP)`:
клиент шлёт UDP-дейтаграммы, собранные вручную (заголовки IPv4 и UDP,
контрольные суммы), сервер отвечает тем же текстом плюс порядковый номер
сообщения от этого клиента (`ip:port`). При завершении клиента (в том числе
по SIGINT) он отправляет серверу служебное сообщение о закрытии, и сервер
сбрасывает счётчик этого клиента.

## Сборка и тесты

```sh
make            # сборка build/bin/echo_raw
make test       # юнит-тесты Unity (root не нужен)
```

## Запуск

Raw-сокеты требуют прав root (CAP_NET_RAW):

```sh
sudo ./build/bin/echo_raw -s [-p порт]        # сервер (порт по умолчанию 5000)
sudo ./build/bin/echo_raw -c 127.0.0.1 [-p порт]   # клиент
```

или через цели `make run-server` / `make run-client` (и `run-cross-01-server` /
`run-cross-01-client` из `module3`).

Клиент читает строки с stdin и отправляет их серверу; ответы печатаются по мере
получения. Завершение — по Ctrl+C или EOF на stdin, перед выходом клиент шлёт
сообщение о закрытии.

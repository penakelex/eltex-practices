# Задание 7: чат через TCP-сокеты с сервером

Клиент-серверный чат: специальное приложение-сервер принимает подключения
и пересылает сообщения каждого клиента всем остальным. Дополнительно
клиенты могут отправлять файлы командой `/file <путь>` — сервер пересылает
файл каждому участнику, тот сохраняет его как `<имя>.received`.

- Сервер использует **epoll** для одновременной работы с множеством
  клиентов.
- Клиент использует **poll** для одновременного чтения сокета и stdin.
- При завершении (Ctrl-C или конец ввода) клиент отправляет `LEAVE`.

## Сборка и запуск

```bash
make

# терминал 1: сервер
./build/bin/chat_server <port>

# терминалы 2..N: клиенты
./build/bin/chat_client <address> <port> <name>

# пример
./build/bin/chat_server 5000
./build/bin/chat_client 127.0.0.1 5000 alice
./build/bin/chat_client 127.0.0.1 5000 bob
```

В клиенте: обычная строка — сообщение всем, `/file <путь>` — отправка
файла, Ctrl-C — выход.

## Тесты

```bash
make test              # реестр клиентов, TCP-обёртки, передача файлов
make test-integration  # сервер + два клиента: текст, файл, выход
```

## Структура

- `include/tcp_socket.h` — обёртки над TCP (`connect`/`accept`/`send_all`/
  чтение кадра по заголовку).
- `include/client_registry.h` — динамический список клиентов с рассылкой.
- `include/file_transfer.h` — отправка файла чанками и приёмник файла.
- `src/chat_server.c` — epoll-цикл сервера.
- `src/chat_client.c` — poll-цикл клиента.
- Протокол пакетов, разбор ввода, вывод и сигналы — в общей библиотеке
  `../06-07` (`libchat_common`).

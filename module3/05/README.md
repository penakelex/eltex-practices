# Задание 5: Производитель-Потребители (POSIX sem + shm)

Модель «Производитель-Потребители» на именованных POSIX-семафорах и
POSIX-разделяемой памяти (`sem_open`, `shm_open`/`mmap`). Бизнес-логика —
в общей библиотеке `../04-05`; этот модуль содержит только POSIX-реализацию
IPC-слоя (`ipc_posix.c`, vtable из `ipc.h`) и разбор аргументов.

Производитель периодически генерирует массивы случайных чисел и записывает их
в разделяемую память. Каждый блок устроен как узел односвязного списка:
заголовок с количеством элементов и смещением следующего блока (0 — последний).
Когда память исчерпана, производитель ждёт, пока потребители не обработают
все наборы, и завершает работу, удаляя семафор и разделяемую память.

Потребители (можно запускать несколько) периодически читают необработанные
наборы, находят минимум и максимум, выводят их и помечают набор обработанным
(количество элементов = 0). Доступ к памяти синхронизируется семафором.

## Сборка и запуск

```
make            # сборка приложения (соберёт и ../04-05)
make test       # юнит-тесты (Unity)
make test-integration
make run ARGS="-p /m3t5 4096"     # производитель
make run ARGS="-c /m3t5"          # потребитель (в другом терминале)
make run ARGS="-p default 4096"   # имя по умолчанию /eltex_practice05
```

Первым аргументом указывается базовое имя POSIX-объектов: к нему добавляются
суффиксы `_shm` и `_sem`. Имя должно начинаться с `/` и не содержать других
слэшей.

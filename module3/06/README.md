# Задание 6: групповой чат через UDP broadcast

Равноправные клиенты обмениваются сообщениями через широковещательную
рассылку (`255.255.255.255`, `SO_BROADCAST`) по UDP. При запуске клиент
рассылает пакет `JOIN`, при завершении (Ctrl-C или конец ввода) — `LEAVE`.
Свои собственные пакеты клиент игнорирует (фильтр по имени отправителя).

## Сборка и запуск

```bash
make
./build/bin/udp_chat <port> <name>

# пример: два клиента в разных терминалах
./build/bin/udp_chat 5000 alice
./build/bin/udp_chat 5000 bob
```

## Тесты

```bash
make test              # юнит-тесты обёрток над UDP-сокетом
make test-integration  # два экземпляра чата обмениваются сообщениями
```

## Структура

- `include/udp_socket.h` — обёртки над `socket`/`bind`/`sendto`/`recv`.
- `include/udp_chat.h` — точка входа приложения.
- `src/udp_chat.c` — главный цикл на `poll` (stdin + сокет).
- Протокол пакетов, разбор ввода, вывод и обработка сигналов —
  в общей библиотеке `../06-07` (`libchat_common`).

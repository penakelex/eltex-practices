# Module 3: System Programming

Практики по системному программированию на C под Linux: процессы,
межпроцессное взаимодействие, сокеты, сигналы, семафоры.

## Архитектура

Каждое задание — независимый подмодуль со своим `Makefile`, `include/`,
`src/` и `tests/`. Подмодули подключают общие фрагменты из `mk/`
(`common.mk`, `app.mk`) и следуют соглашениям `module2`.

| Подмодуль | Тема | Статус |
| ------------- | ------------------------------------------------------------ | -------- |
| `01/` | fork + файлы + каналы | готово |
| `02/` | System V message queues + сигналы | готово |
| `03/` | POSIX message queues + сигналы | готово |
| `04/` | System V семафоры + разделяемая память | готово |
| `05/` | POSIX семафоры + разделяемая память | готово |
| `06-07/` | общая библиотека чатов (протокол, ввод, вывод) | готово |
| `06/` | UDP-сокеты (групповой чат) | готово |
| `07/` | TCP-сокеты + мультиплексирование | готово |
| `08/` | UDP raw сокеты (перехват UDP-сегментов) | готово |
| `cross-01/` | raw сокеты + САОД + сигналы | — |
| `cross-02/` | fork + poll/epoll/select + таймеры + IPC | — |

## Сборка и запуск

```bash
# Собрать всё
make

# Запустить задание 1
make run-01 ARGS="file1.txt file2.txt"

# Запустить задание 2 (брокер)
make run-02 ARGS="-b"

# Запустить задание 3 (p2p-чат, запускать в двух терминалах)
make run-03 ARGS="demo"

# Запустить задание 4 (производитель; ключевой файл создаётся автоматически)
make run-04 ARGS="-p /tmp/m3t4.key 4096"

# Задание 4, потребитель (в другом терминале, можно несколько)
make run-04 ARGS="-c /tmp/m3t4.key"

# Задание 6 (UDP-чат, запускать в двух терминалах с одним портом)
make run-06 ARGS="5000 alice"
make run-06 ARGS="5000 bob"

# Задание 7 (TCP-чат: сервер, затем клиенты)
make run-07-server ARGS="5000"
make run-07 ARGS="127.0.0.1 5000 alice"

# Задание 8 (перехват UDP-сегментов; требуется root или CAP_NET_RAW)
sudo make run-08 ARGS="-f dns -o capture.txt"
sudo make run-08 ARGS="-f chat -p 5000"
sudo make run-08 ARGS="-f all"

# Собрать/протестировать только задание 1
make -C 01
make -C 01 test
```

Цели `run-01` .. `run-08`, `run-cross-01`, `run-cross-02` определены в
корневом `Makefile` и пробрасывают `ARGS` в соответствующий подмодуль.

## Пример: перехват UDP-сегментов (задание 8)

Программа `08/` захватывает копии UDP-сегментов через RAW-сокет.
Доступные фильтры: `chat` (чат из задания 6, порт через `-p`), `dns`,
`dhcp`, `ntp`, `mdns`, `quic`, `all`. Фильтры комбинируются через
запятую: `-f dns,chat` захватывает и DNS, и сообщения чата.

Типичный сеанс захвата DNS-трафика:

```bash
# Терминал 1: запустить захват (завершение — Ctrl+C)
sudo ./08/build/bin/udp_sniffer -f dns -o capture.txt

# Терминал 2: породить DNS-запросы
dig example.com
```

После Ctrl+C в терминале 1 появится список перехваченных сегментов
(он же сохранится в `capture.txt`):

```
captured 2 segment(s)
+    3.212s MAC aa:bb:cc:dd:ee:ff -> 11:22:33:44:55:66 IP 192.168.1.2:53321 -> 192.168.1.1:53 len=35 dns=example.com
+    3.234s MAC 11:22:33:44:55:66 -> aa:bb:cc:dd:ee:ff IP 192.168.1.1:53 -> 192.168.1.2:53321 len=67
```

Перехват сообщений чата из задания 6 (чат запущен с портом 5000)
вместе с DNS-трафиком:

```bash
sudo ./08/build/bin/udp_sniffer -f chat,dns -p 5000
```

## Тестирование

Для тестирования используется фреймворк **Unity**. Он скачивается
автоматически при первом запуске тестов (в папку `third_party/Unity`).
Сборка тестов изолирована от основной сборки.

```bash
# Все тесты модуля
make test

# Тесты конкретного задания
make -C 01 test

# Интеграционный сценарий задания 4 (производитель + два потребителя)
make -C 04 test-integration
```

## Инструменты разработки

- `make format` — автоматическое форматирование (требуется
  `clang-format`).
- `make format-check` — проверка форматирования (используется в CI).
- `make install-hooks` — активация `pre-commit` и `pre-push` хуков.
